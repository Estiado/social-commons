# 数据库文件

| 目录 / 文件 | 用途 |
| --- | --- |
| `migrations/` | 新增或调整表结构、权限的有序迁移；先核对目标库和执行记录 |
| `seeds/reading_catalogue.sql` | 公共精选文章的元数据，不含私人全文 |
| `seeds/essay_examples.sql` | 站方推荐素材示例 |
| 根目录旧 `*.sql` | 早期初始化和兼容历史，不是日常升级入口 |

不要通过重跑 `init.sql` 重建现有数据库。实际生产迁移记录见 [验证记录](../docs/VERIFICATION.md)。旧收藏通过网站的“旧资料导入”只读复制，不删除源表。
