# 网页源码

| 目录 / 文件 | 放什么 |
| --- | --- |
| `pages/` | 网站的每一个页面，按页面名分文件夹；页面负责组织交互 |
| `features/reading/` | 阅读空间：内容转换、划线收藏、文章存储、摘录、素材包、导出 |
| `features/essay/` | 用户自己添加的概念素材、站方推荐示例 |
| `features/auth/` | 邮箱账号界面，默认关闭，待邮件验收 |
| `data/` | 内置通识、名句、历史、经典文章和精选目录 |
| `components/` | 导航、搜索、错误提示与通用界面 |
| `components/ui/` | 通用控件，不放业务代码 |
| `hooks/`、`lib/` | 跨模块的小工具 |
| `app.tsx` | 页面网址和组件的对应关系 |
| `index.tsx`、`index.css` | 网页启动和全局样式 |

内容导入共用阅读模型，避免各页面分别维护一套收藏代码。完整文件导览见 [中文目录导览](../docs/REPOSITORY_GUIDE.md)。
