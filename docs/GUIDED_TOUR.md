# 首次使用指引

## 读者如何使用

第一次进入网站会出现欢迎弹窗。点击“开始浏览”，从首页向下认识摘读、日新、时评、主题与群鉴；随后进入群鉴词条、阅读空间、议论文素材，回到顶部导航认识日新、撷英、观澜、全站搜索，最后进入内测反馈。共25步。

每一步都可前进、后退、关闭或跳过。完成或关闭后，当前浏览器不再自动弹出；页脚“使用指引”和手机栏目菜单均可重新打开。更换浏览器或清理站点数据后会重新提示。

引导只导航、滚动和展开栏目/备份区，不替读者保存文章、收藏、导出或提交反馈。开始前留在原页；开始后使用替换导航，避免在浏览器历史里堆积25页。

## 维护入口

- `src/features/onboarding/steps.ts`：步骤顺序、真实路径、目标标记与中文说明。修改栏目时一起核对这里。
- `GuidedTour.tsx`：跨路由定位、平滑滚动、聚光区域、提示卡、键盘焦点与清理。
- `preferences.ts`：当前浏览器是否已看过；不能读取存储时不强制弹窗。
- `tour.css`：提示卡和轻动画。手机卡片位于底部，支持安全区、内部滚动与系统减少动态效果偏好。
- 页面目标用 `data-tour="…"` 标记；布局的 `data-tour-shell` 在引导中暂设为inert，关闭时还原原状态和焦点。

已有GSAP依赖按需加载，使用ScrollToPlugin移动到目标，useGSAP清理卡片动画。每步取消旧的滚动、观察器、计时器和动画帧；目标尚未出现时等待DOM，7秒后提供重试/继续，不留下卡死遮罩。进入导航步骤时回到页首，窄屏自动展开栏目菜单。备份步骤先展开details再测量目标。

设计参考：[Lenis](https://github.com/darkroomengineering/lenis)的平滑滚动体验、[GSAP React](https://github.com/greensock/react)的动画清理方式，以及[React Bits Stepper](https://github.com/DavidHDev/react-bits/blob/main/src/ts-tailwind/Components/Stepper/Stepper.tsx)的分步进度与前后操作。代码为本站实现，未复制第三方组件源码，也未新增Lenis依赖或接管全站滚动。

## 验收

检查桌面与390px手机的全部25个目标、跨页后定位、菜单展开、备份区展开、上一步、关闭/跳过、Esc、重新打开和刷新后不重复提示。系统减少动态效果时，滚动和卡片动画时长为0，CSS呼吸与过渡停用。新增目标不可依赖某位读者已有文章或登录身份。
