## 来源如何使用

新增通识的概念说明依据 NobelPrize.org、OpenStax、斯坦福哲学百科、美国统计学会、美国国家科学院、UNESCO、Digital Inquiry Group 与作者论文。内容是本站短摘要，不是复制整篇论著。本轮撤去自拟课堂问题，保留概念边界和具体出处。算法公平条目明确依据作者预印本，不能写成学界唯一结论。

历史主题引用美国国会图书馆、美国国家公园管理局、CDC 历史教材和 UNEP 的馆藏、档案与机构资料；不加入课堂讨论，不伪造当事人发言或论文。印刷史区分木版与活字、现存实物与发明过程。历史教材的存在不代表网站提供医疗指导。

诗词解读采用以下具体已发表资料的短摘要，逐条作者与有题名的来源链接随条目显示，核验日期保留内部：

## 教学提示与真实素材

15 个新增示例中，概念研究的短摘要与虚构课堂设例均明确标注。设例中的两小时、90% 等不能当作调查数据引用。教师可将概念、段落和自己的问题编入文稿；暂不新增“标准答案”栏目，也不承诺覆盖特定省份全部考纲。

近期时评是公开目录元数据，原媒体全文仍由读者导入个人空间。新增 10 篇的标题、日期与署名来自原媒体页面或公开索引，未署名保持空值，不将责任编辑当作者。推荐语是本站教学说明。收录不代表抓取可用、全文授权或所述数据已被本站重新调查；也未按点击量排名为“十大热点”。

## 维护顺序

1. 在相应领域文件增加内容，保留旧 ID；长文件再按领域拆分，页面不要直接塞正文。
2. 打开具体来源，找到支持摘要的部分；区分原文、转述、报道和教学设例。
3. 维护 `topicSpecials.ts` 的关联 ID。重复作品使用 canonicalId，不重复推荐。
4. 运行 `npm run seed:catalogue`、`npm run seed:examples` 更新可选 SQL 副本；生成不等于执行生产数据库。
5. 运行 `npm run check`，检查文字保留、私有快照与导出。提交并核验 GitHub、Cloudflare。

私人保存的是当时的文本快照。站内正文修订后，不迁移或覆盖旧划线；新版单独保存，旧件仍在阅读空间。
