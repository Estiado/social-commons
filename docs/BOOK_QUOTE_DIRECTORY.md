# 撷英编目说明

2026-11-01。用户要求参考百科全书，按中外、朝代等组织目录。本轮是在已有作品上建立阅读索引，不复制百科条目或代码，也不改写署名与原文。

## 层级

中外分卷 → 朝代／时期 → 作者／典籍 → 作品。当前规范作品100篇，中文84篇、外国16篇；数据仍来自`QUOTE_CATALOGUE`，没有重新加入已撤回或合并的重复条目。

- 中国：先秦、先秦两汉、汉、三国两晋南北朝、唐、五代十国、宋、元、明、清、近现代。仅显示当前有作品的层级，顺序按时期；“先秦两汉”用于《礼记》这种跨先秦材料与汉代编纂的典籍，不将其伪装成某一年的个人著作。
- 外国：18—19世纪、19—20世纪之交、20世纪及以后。是按主要活动与创作时期建立的浏览区间，不是每部作品的出版年代，也不是穷尽世界文学史的划分。无国别元数据时不根据姓名自动猜国籍。
- 同期人物与典籍采用中文拼音索引；同一作者下保留作品原顺序。按书名署名的《诗经》《礼记》《左传》仍以典籍出现。“杜秋娘（传统署名，作者有异说）”完整保留；佚名只对已知《行行重行行》《迢迢牵牛星》归汉，其他未来佚名作品进入待考。

## 兼容与维护

- `quoteDirectory.ts`维护时期映射、里尔克别名和目录纯函数；`catalogue.ts`只加索引字段及搜索词，不改变原文、ID或URL路径。
- 新路径例如`?category=中国/宋/苏轼`，URL由URLSearchParams编码；旧`?category=苏轼`及里尔克别名仍到达对应作品。直接文章链接、canonicalId及导出继续使用原模型。
- 返回恢复各级分页，搜索词和计数基于筛选后的实际作品。按作者遍历所有叶子应恰好覆盖规范目录一次，不能因多个索引漏篇或重复计数。
- 新作者不按字形或语言猜归属，fallback显示待考；回归测试要求当前正式编目的作者都已明确映射，新增内容需同步核对。

- [Academy of American Poets：Rainer Maria Rilke](https://poets.org/poet/rainer-maria-rilke)：核对1875—1926及其跨世纪创作活动，目录合并中文译名，未复制传记正文。
- [中国哲学书电子化计划：《礼记》图书资料](https://ctext.org/wiki.pl?if=gb&remap=gb&res=5893701)：编目年代记汉；结合其所收先秦材料，本站使用“先秦两汉”的范围标签。
