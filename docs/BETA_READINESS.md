# 内测评估与使用边界

更新：2026-10-23。代码检查、浏览器验收和线上数据库审计是不同证据，最终发布状态以 `VERIFICATION.md` 为准。

## 当前适合怎样发给别人

建议先邀请 10—20 位同学或老师做一次 48 小时的小范围内测。这个人数是组织反馈的建议，不是压测容量。先让大家完成“读一篇并划线 → 只选需要的条目编成文稿 → 下载或备份”三个任务，收集不能完成任务的问题，再扩大范围。微信链接受来源站限制，继续按用户决定延期，不能宣传所有链接都能自动取得全文。

拿到正式链接后，访客可阅读公共内容、导入私人正文、收藏、编辑和导出，无需运行 CMD。每个人的阅读空间在各自浏览器中；转发网站链接不会把自己的私人文章一并分享出去。用 Safari/Chrome/Edge 等普通浏览器打开比在聊天软件内反复切换浏览器更便于持续保存。

## 本地数据会不会丢

IndexedDB 和 localStorage 通常会跨关闭页面、退出浏览器和关机重启保留。临时导入的文章按产品规则保留七天，主动保存或收藏后去掉到期时间，文稿持续本地保存。这不等于永久云端备份。

清理网站数据、隐私模式结束、浏览器/手机切换、系统空间不足时的浏览器清理，都可能让数据不可用。应用内浏览器与外部浏览器也可能使用不同存储空间。浏览器还可能有自己的自动清理策略。参见 [MDN 存储与清理说明](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。

现在提供“数据与备份 → 下载可恢复备份”。恢复只添加缺失记录，不覆盖本机文章、文稿或划线；到期的临时记录不会借恢复自动延长。备份包含当前浏览器的阅读文档、标注和文稿，最大 50 MiB、每类最多 1000 条；不包含云端和议论文页面的自定义素材。素材区有独立备份。旧整库 ZIP 作为其他导出保留，不冒充新恢复格式。

备份文件含个人正文，应由用户自行保管。网站不替用户将文件传给维护者。

## 要不要立即上账号

小范围试用可先保持免登录。稳定后再做邮箱验证码、长期云端保存和跨设备同步，并完成 SMTP 配额、重发/频率限制、两个真实账号隔离、找回与删除数据等验收。现在不启用邮件和新账号同步，界面不能承诺跨设备找回。账号会改善找回能力，也增加隐私、邮件运维及数据库成本，不能只加一个登录按钮便宣布完成。

| 接口资源 | 白名单、重定向检查、请求体大小、抓取超时、响应/图片大小和单实例频率限制已有回归。分布式限流绑定是否配置仍需 Cloudflare 运维核查；本轮未做并发压测或渗透测试。 |

## 会不会崩溃、花多少钱

公共页面和文件由 Cloudflare 提供；`_routes.json` 只把 `/api/*` 交给函数。私人阅读和编辑主要在访客设备执行，因此多几个阅读者不等于一台本机开发服务器同时承担所有人。提取和图片代理仍受 Workers 额度、来源站和网络影响，数据库也有自身限制；见 [Cloudflare Pages 限制](https://developers.cloudflare.com/pages/platform/limits/)。

不能据此保证“不会崩”。目前没有负载测试给出的并发上限。手机导出长文、图片多、内置 PDF 中文字体下载，以及大量同时提取，是应重点观察的压力点。首次扩散前应确认 Cloudflare 的错误/用量面板和 Supabase 的配额；遇到配额或来源故障，先说明具体失败，保留本机资料和已能使用的静态阅读。

## 怎样处理反馈

菜单、页脚提供“内测反馈”。访客写明操作、结果和期望，复制或下载文本文件后发给邀请者；页面明确显示尚未发送。不会自动读取文章、收集设备信息或开放在线投稿。

维护者收到后先分为：数据丢失/隐私问题（立即停止扩散、备份和定位）、阻断核心操作（优先修复）、内容纠错（核对原始出处）、体验建议（合并同类后排序）。GitHub Issues 可作为维护者的问题清单，私人文章、联系方式和截图中的敏感信息不直接公开贴上去。严重问题用 Git revert 回退代码或 Cloudflare 历史部署，不能清空数据库“恢复”。

## 和同学协作的权限

公开 GitHub 仓库不会让访客获得写权限。建议同学 Fork 后提交 PR，由站长检查后合并。2026-10-23 的 GitHub 分支接口显示 main 尚未开启保护；不要向有写权限的 Collaborator 承诺其无法改 main。扩大协作前由站长设置要求 PR/检查、禁止强推/删除主分支，并核对管理员绕过范围。本轮没有邀请成员或扩大账号权限。

完整操作见 [同学协作说明](CLASSMATE_COLLABORATION.md)。Git 历史保护代码版本，浏览器和数据库内容需要各自备份。
