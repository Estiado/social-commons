# 知天下与每日简报

## 阅读入口

- `/world`：长期事件目录，支持标题、简介与关键词检索。
- `/world/:id`：以连贯长读为主，依次讲清经过与因果；最近进展、背景索引、原文短引和其他视角作补充。当前俄乌16、巴以9、2030议程7、法国2026年抗议9、红海航运9个时间书签，共50个。
- `/briefing`：北京时间当天的简报；`?date=YYYY-MM-DD`打开指定日期，非法日期及未来日期有恢复入口。
- `/guanlan/events/global-risk-2026`：联合国2026年全球风险报告分析，与三个长期事件互相连接。

每日简报在新打开或刷新网站时弹出，站内切换页面不会反复弹出。可关闭、按Escape退出，或从导航和页脚重新打开。首次使用指引等简报关闭后再出现；点击简报内容时，本次访问不再紧接着启动指引。

## 内容更新方式

这是按日轮换的编辑选读，不是自动采集新闻、后台定时任务或系统通知。新闻从截至当天的最近五条已维护材料中轮换，并显示资料日期；完整古典作品和概念分别轮换。北京时间零点及手机休眠后回到页面时刷新当天日期。

同一天的选择在同一内容版本中一致。新增或调整目录会影响以后重新打开的历史简报；已加入阅读空间的快照仍保留原内容，不随公共稿修改。

维护新闻时，先更新事件正文，再同步轻量目录的`latestEventDate`、简介与核对日期。不要把新闻发布日期当成事件日期，不要把拟议会谈、声明或假设情景写成已经发生的结果。过时材料需要编辑更新，本系统不会自行核验新进展。

本站编写正文继续只改`content/站内编辑稿.md`，相关组为`world/catalogue`、`world/ukraine`、`world/palestine`、`world/un2030`、`world/france`与`guanlan/globalRisk`；观澜入口文字放在原有`guanlan/catalogue`组。原作者诗文、出处链接和书目信息仍在各自数据模块。操作见[编辑稿维护](EDITORIAL_COPY.md)。

每篇的`context`解释地理、参与者和制度背景，`questions`回答容易混淆的问题，两者均逐节关联`sourceIds`。`excerpts`只保存核对过的短引、来源ID和具体定位；二手报道引述他人时，在定位中注明发言人及报道作者。引用与本站解释以阅读块区分，导出仍保留出处。不要把编辑摘要写进引号，也不要把历史来源中的当时判断当成今天的定论。

2026-10-28起，`narrative`是主文，按章保存连续段落、来源及`timelineIds`。每个timeline ID必须且只能关联一个章节；一章可以包含几个相关日期，正文里直接写明经过，时间下拉框仅跳至所在章节。timeline不再保存另一份what/why短摘要，避免两套叙述不同步。维护时先写主文，再登记书签，最后同步简介与更新日期。红海的本站正文在`world/redsea`组。

导语之后直接进入主文，再读最近进展和补充。桌面目录优先展示主文章节，“资料与补充”可展开；手机目录默认收起，保留时间选择器。所有章节、引用和出处仍在统一阅读模型里，收藏与导出不依赖页面额外拼接。

## 数据和性能边界

正文按事件加载，目录、导航与全站搜索不加载各篇全文。知天下与简报通过既有阅读器保存文章、段落和划线，转成独立文稿后可编辑及导出Word/PDF；没有新增数据库表、迁移私人数据或启用邮件登录。

2026-10-28增补`world/aiEnergy`，6章7书签解释数据中心、电量与功率、接网、效率与总需求、费用和地方资源。统计期书签使用年份精度，不冒充报告当日发布；2024/2025估计与2030预测明确分开。当前6篇共33章57书签。轻目录的`sourceNames`只登记实际资料机构，为全站检索提供媒体筛选，不把正文下载进索引。

公开资料仍是静态编译内容。收藏使用内容散列区分版本，不覆盖旧正文和标注。日期节点保留来源实际的年月精度，`date`只负责排序；每个节点和来源视角关联可追溯的书目ID。

界面沿用纸色、衬线字和朱色链接，滚动由浏览器处理。桌面导航增加栏目后，完整导航断点统一改为1280px，窄屏使用菜单；指引的导航判断采用相同断点。没有为新页面引入背景视频、3D效果或新依赖。

## 验证

运行`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1 check`。新增回归覆盖北京时间跨日、非法日期、连续70天选择差异、节点顺序与来源关联、原型名称防护、阅读器/编辑器往返、完整诗文和报告统计口径。浏览器还需检查弹窗、目录定位、手机菜单、刷新后保存及正式部署；自动测试不代替这些步骤。
