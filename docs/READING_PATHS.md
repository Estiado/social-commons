# 日新与群鉴的阅读入口

2026-11-02：依据用户确认，减少概念与案例同级堆叠。高中生和大学生仍并重；本轮照顾周日阅读时间有限的使用场景，没有新增备课、课堂讨论或答题任务。

## 读者看到什么

- 日新默认显示一组有顺序的短读，共三篇；六条阅读线分别串起选择、证据、标签、学习、社会影响和技术变化。可用选择框换组。
- 群鉴默认显示一组两三篇并读，另保留四篇历史长读作为入口。科学史等较细案例通过主文下方的关联阅读进入；原16条事件都能在完整目录检索。
- 推荐按北京时间周一轮换，每周内保持同一组。它是已编辑内容的轮换，不宣称每周自动采集或新增。
- 两栏搜索始终可见，输入后直接打开完整目录并显示结果数，按Enter定位结果。清空搜索恢复阅读入口；全部目录也可手动展开。日新分批显示18条，筛选和查找覆盖147条全部内容。
- 详情页末尾解释与同组其他条目的联系，并直接链接下一篇。每篇仍独立阅读、划线、保存及导出；不会把多个原文拼成一篇新的私人文档。

## 文件职责

- `src/data/readingPaths.ts`：稳定阅读线ID、原条目ID及默认主目录。文字引用统一编辑稿，条目标题取原数据，不重复复制。
- `content/站内编辑稿.md`的`readingPaths`组：标题、导读、并读联系和逐篇说明。共57字段；可以直接编辑，构建时生成。
- `src/features/discovery/selection.ts`：周一轮换与详情页归属校验。
- `src/features/discovery/ReadingPathSection.tsx`：阅读顺序、切换及详情关联导航。
- `DailyPage`和`EventsPage`：索引、搜索、原生details目录。既有新手指引目标保留。

没有删除、合并或改号原文章；原来源与阅读块不变。全站搜索、私人快照、划线偏移和导出继续读取原模型。未修改数据库或复制站。自动检查和实际发布见VERIFICATION.md。
