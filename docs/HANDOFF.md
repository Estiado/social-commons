## 仍须明确的边界

- SMTP 与真实账号保存、隔离、同步未验收，`VITE_READING_CLOUD_ENABLED` 默认 false。

- 新表迁移与种子已执行的历史状态见验证记录；不要重跑旧 `supabase/init.sql` 初始化整库。
- 名句只有已核验的资料摘要显示评析，其余待核验。内置其他内容的存在不代表所有史料、译文和论文条目已逐条核验。

- PDF 中文字体约 10.6 MB，仅导出时加载。Word 已校验 OOXML，当前 Windows 无 LibreOffice，未完成 Word 版式视觉验收。
