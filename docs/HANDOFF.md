本轮范围见 [开发清单](DEVELOPMENT_PLAN.md)：网站内编辑器、统一选材、观澜与专题合并、7—10 月 40 篇时评和验证拦截页识别。交付证据与发布状态见 `VERIFICATION.md`。

## 用户当前要求

- 日常使用正式网站 `https://social-commons.pages.dev/`，不要求用户启动本机服务。邮箱、跨设备同步延期，当前在浏览器内保存。
- 日新、撷英、群鉴、时评、专题和素材内容共用阅读模型；支持段落收藏、划线、加入阅读空间。
- 导航只保留阅读空间，统一列出文章、摘录与独立文稿，选择后编为一份可编辑并下载的 Word/PDF；旧收藏、备注与原件不能丢失。
- 工作、缓存、构建与验收产物放 D 盘。交付包括提交、GitHub 推送、远端 SHA 与 Cloudflare 验收，不强推。

先读 [目录导览](REPOSITORY_GUIDE.md)，按 [架构](ARCHITECTURE.md) 查需要的模块，避免一次读取全站内容。模板 `src/index.tsx` 和通用 `components/ui` 保持稳定。

## 本轮结构

- 新阅读业务集中到 `src/features/reading`；不再分别维护站内模块和媒体文章的划线逻辑。
- 旧 `/paragraphs`、`/collections` 链接保留重定向，旧数据库表不删除。显式导入使用原浏览器已有身份，不创建新匿名账号；迁移后的旧摘录标为节选。
- IndexedDB V3 原位增加文稿与摘要，V1 的游标摘录升级继续保留。正文、摘要与摘录在同一事务更新；旧文档 ID、期限、收藏保留。
- 旧素材包转为文稿，保留备注和顺序；originKey 防止重复迁移覆盖编辑内容。整库 ZIP 仍附旧素材包关系。
- 观澜先按主题组织，媒体目录与私人关联分开；专题导入保留上下文。旧 `/topics/:id` 重定向到 `/guanlan/topics/:id`。
- `writing/` 集中文稿模型、存储、编辑器 JSON 转换与编排；650ms 自动保存，版本冲突明确报错。旧独立管理界面清理，原件不删除。
- 日新五个大类加细学科下拉；40 篇时评公开元数据，推荐理由标本站整理；生产 SQL 更新与站内目录发布分开记录。
- 无调用方的旧匿名登录、同步助手、重复段落/素材包页面已清理，原代码在 Git 历史。
- Netlify、妙搭兼容文件归入 `config/`；Cloudflare 的 `functions/api/` 保留平台约定位置。
- CMD 位于 `scripts/windows/开发预览.cmd`，仅维护者使用。重复启动识别现有本站服务，不杀进程或换端口。

## 错误修复与验证

“丝绸之路”实际报错为动态模块加载失败；开发依赖 `@radix-ui/react-tabs` 返回 504 Outdated Optimize Dep。现预优化依赖，页面简化为共享阅读器；错误边界遇到过期模块提供整页重载，避免 React.lazy 缓存失败后的无效重试。

新增回归覆盖所有内置内容转换、V1 原位升级、摘录索引一致性、旧资料追加迁移、素材包去重/备注与缺失条目、过期模块识别。详细自动和真实浏览器验收见 `VERIFICATION.md`。不能把模拟迁移当作真实生产账号验收。

## 仍须明确的边界

- SMTP 与真实账号保存、隔离、同步未验收，`VITE_READING_CLOUD_ENABLED` 默认 false。
- 旧数据库权限尚需专项审计；移除重复页面不等于修改了旧表 RLS。旧资料只读迁移必须检查每次查询返回的错误。
- 新表迁移与种子已执行的历史状态见验证记录；不要重跑旧 `supabase/init.sql` 初始化整库。
- 名句只有已核验的资料摘要显示评析，其余待核验。内置其他内容的存在不代表所有史料、译文和论文条目已逐条核验。
- 媒体可能只返回节选或拒绝抓取；阅读和导出都应保留完整性提示。
- PDF 中文字体约 10.6 MB，仅导出时加载。Word 已校验 OOXML，当前 Windows 无 LibreOffice，未完成 Word 版式视觉验收。
