# 接手记录

更新：2026-10-20。仓库 `Estiado/social-commons`，生产分支 `main`，部署在 Cloudflare Pages。

## 当前目标

提高代码可读性、维护性与加载效率；修复实际搜索/收藏/导出问题；所有新增工作文件在 D 盘；将修改同步 GitHub。用户允许必要时重构仓库，但本轮沿用历史。

## 已完成

- 页面与搜索弹窗按需加载，Word 库点击导出才加载。
- 搜索改为只读索引、纯函数检索、最多 30 条早停，关闭 cmdk 二次过滤；定位到通识、名句和议论文具体条目。
- 观澜静态内容一次转换，云端只拉取最近 100 篇，URL 去重、内存筛选、一次话题计数；保留显式分类并修复专题 tag 参数。
- 提取/通用话题规则前后端复用；Cloudflare Pages 与 Netlify 通过薄适配层调用同一服务。登录校验、媒体白名单、跳转检查、超时和响应流上限已实现。
- Supabase 写入显式检查错误；经典文章保存用云端段落 UUID；登录失败不再使用伪云端 ID；多组件共用身份初始化。
- 导出逻辑从 789 行素材包页拆出；支持只有划线的素材包，打印 HTML 转义，导出均保留原文地址；修复连续排序本地 sort_order。
- localStorage 通过外部快照订阅处理同标签页/跨标签页同步，函数更新读取最新值。
- 已提供 Windows D 盘运行脚本、25 项回归测试、前后端类型检查、函数打包检查和产品/架构文档。

## 验证与操作入口

`npm run check` 或 Windows `scripts/dev.ps1 check`。具体事实见 `docs/VERIFICATION.md`。测试、截图、缓存、临时函数产物在 `.artifacts/`，不进 Git。

本地预览在当前会话验证过 `http://127.0.0.1:5174`。内嵌浏览器此前连接超时，改读用户已打开的 Edge 后完成真实页面验证；本地预览进程需要允许浏览器访问其监听地址，不要修改系统隔离设置。

## 仍需后续解决

1. 内容与作者解读逐条核验、重复条目处理，见产品蓝图。
2. 实际 Supabase RLS 与服务端配额审计；本轮没有执行线上 SQL 或改 Secret。
3. 跨设备正式身份与自定义条目备份。
4. 经典段落同步和排序的数据库事务/唯一约束；当前有本地并发合并和失败恢复，但不等于多客户端事务。
5. 观澜超过最近 100 篇、全站搜索接入文章/自定义材料，需要分页与权限设计。

不要把单元测试的模拟 Supabase 写入当成真实云端写入验收。不要凭页面上显示“管理员”判断当前身份有删除权限。
