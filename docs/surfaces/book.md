# 书页预览：总目录、分类与阅读

更新2026-10-30，仅 codex/book-preview。产品事实沿用PRODUCT.md。总目录为Experience；分类/正文为Read；阅读空间为Operate。

THESIS: 读者置身低视角纸面，从浮起的六章目录进入摊开的书页，再从分类走向文章。

OWN-WORLD: 米白、墨色宋体、赭色焦点、真实1846年千字文扫描；纸面弧度、侧光和窄书缝建立深度。正文仍是可选择、可保存的语义文字。

STORY: 总目录 → 栏目分类 → 篇目 → 正文。分类标题从原位置移动到篇目页页首；返回恢复分类分页。首页所选词条逐字移动为栏目标题，其他字融入云团，摊开的书同时浮现；此段不翻页。之后公开导航才翻页。

FIRST VIEWPORT: 品牌在右、六章竖排在左，纸面构成云海基底，云雾沿纵深漂浮，透出古籍字迹；鼠标推开局部并带动回流。桌面栏目为跨页；手机为单页，并保留44px点击区。

FORM: 依据用户连续提供的实图与三条最终要求直接实现。早期完整封皮/书房comp已被用户否定；book-a不再是批准的视觉基准，不声称旧comp门禁已通过。最终视觉与实际素材说明见BOOK_DESIGN_PLAN.md。

FINISH: 当前代码以真实浏览器、检查日志、来源记录和最终复核为验收证据；不虚构帧率、数据库或上线结果。

## 明确允许与边界

纸白、漂浮字影、纸张材质渐变、单张主图和仅六章名字均来自用户明确要求。不能为了通过图库通用检测添加无关照片、视频、营销文字或装饰。

屎壳郎卷纸仍是待选实验。本轮采用独立实现、可中断的连续3D纸页，不把它说成已经实现虫子推纸动画。私有文章、编辑、反馈和锚点不接管。

预览禁用Supabase客户端，Pages及本地中间件阻断/api/，加入noindex。只在预览来源存储个人测试数据；不迁移正式用户资料。main不合并、不推广。
