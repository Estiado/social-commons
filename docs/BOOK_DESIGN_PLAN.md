# 书页预览设计与来源

2026-10-30。用户三条要求已完整收齐并授权开始。只改 codex/book-preview，生产 main 不合并、不推广。本文是本轮设计方案，不代表昆虫卷页概念已经实现。

## 方向

首页是置身纸面中的总目录；栏目页是摊开的真实跨页；文章页保持连续滚动。主路径为六章总目录 → 分类 → 篇目 → 正文，搜索和阅读空间保留在书外。受众、来源、存储、收藏和导出边界全部沿用 PRODUCT.md。

颜色：纸白 #f3f0e8，墨绿 #303831，次级墨色 #62695e，赭色 #80513e，内页白 #faf8f2，书缝 #bdb5a3。Noto Serif SC 用于品牌、章节、篇目；Noto Sans SC 用于检索和工具。大标题与目录整体放大约20%，按设备调整；正文维持清楚的阅读字号。文字左对齐，跨页有明确中缝，手机退为单页。

```
总目录：六个竖排章节              社科通识
                     浅纸面与薄雾

栏目跨页：
  分类 / 篇目       书缝       当前篇目、出处、预览
  返回分类                      翻开阅读
```

## 动作分镜

用户已要求替换真实翻页；候选A/B见BOOK_TURN_OPTIONS.md，未选定前不改动翻页算法。本轮先完成50%云雾与按实际云层落点的逐字漂浮修正。

- 悬停或键盘聚焦：章节文字上浮，影子向纸面拉开。触屏点击直接进入相同路径。
- 首页选择章节：选中文字向前上方离场，其余目录和品牌逐渐缩小、倾斜并沉入纸面；随后纸页弯折、慢翻，目标栏目出现。文字飘落约3秒，现有翻页约1秒；翻页替换等待用户选型，Escape可以结束转场。
- 选择分类：原分类标题移动成为篇目页标题，列表随后出现。分类和搜索存入URL，返回可恢复。
- 常规公开页面使用较短翻页；编辑、私人阅读空间、反馈和页内锚点沿用原导航，避免丢失router state、保存或选字。
- 云雾限制在底部约四分之一，50%不透明、细小缓慢；可暂停，减少动态效果时静止，离屏和后台停止绘制。
- 屎壳郎卷皱纸页为独立待选实验：目前没有把这一候选当成全站默认动画。不会把正文滚动改成强制分页。
