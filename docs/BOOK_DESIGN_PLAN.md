# 书页预览设计与来源

2026-10-30。用户三条要求已完整收齐并授权开始。只改 codex/book-preview，生产 main 不合并、不推广。本文是本轮设计方案，不代表昆虫卷页概念已经实现。

## 方向

首页是置身纸面中的总目录；栏目页是摊开的真实跨页；文章页保持连续滚动。主路径为六章总目录 → 分类 → 篇目 → 正文，搜索和阅读空间保留在书外。受众、来源、存储、收藏和导出边界全部沿用 PRODUCT.md。

颜色：纸白 #f3f0e8，墨绿 #303831，次级墨色 #62695e，赭色 #80513e，内页白 #faf8f2，书缝 #bdb5a3。Noto Serif SC 用于品牌、章节、篇目；Noto Sans SC 用于检索和工具。大标题与目录整体放大约20%，按设备调整；正文维持清楚的阅读字号。文字左对齐，跨页有明确中缝，手机退为单页。

```
总目录：六个竖排章节              社科通识
                     浅纸面与薄雾

栏目跨页：
  分类 / 篇目       书缝       当前篇目、出处、预览
  返回分类                      翻开阅读
```

## 动作分镜

用户已选择B，并明确首页不再额外翻页。实现与许可边界见BOOK_TURN_OPTIONS.md。

- 悬停或键盘聚焦：章节文字上浮，影子拉开。触屏点击进入相同路径。
- 首页选择章节：所选词条逐字上浮，竖排逐渐连为横排，成为下一跨页的栏目标题；其余文字约3秒融入底部云团。摊开的书同时浮现，此段没有翻页。整体约3.7秒。
- 选择分类：原分类标题成为篇目页标题，列表随后出现；分类、查询与返回分页仍进入URL。
- 后续公开导航使用3.15秒连续3D纸页；旧左页保持不透明，由移动纸页遮挡，避免重叠字影。编辑、私人阅读空间、反馈和锚点沿用原导航。
- 云层限制在底部约四分之一；60/75/90%比较后暂取75%，保留书页可见度。可暂停，减少动态效果时静止，WebGL不可用时显示相同云层静态回退。
- Escape、减少动态效果或转动屏幕可结束当前转场；私人导航与浏览器Back优先。昆虫卷纸仍是未实施概念，正文不强制分页。

## B选型后的修订 · 2026-10-30

首页不再先消字再翻页：所选词条上浮，逐字连成下一跨页的横排标题；其余字约3秒落入云团，同时书本在背后浮现。后续公开导航才运行3.15秒的连续3D纸页。原三段折板完全移除，不再复制、拼接三块DOM。

纸面采用独立弧长积分几何与WebGL正背面纹理，无新包；参考项目只借鉴可见形变，不拷贝未声明许可的源码。DOM纹理只含当前可见公共内容，私人路由仍不接管。云层由平面FOG改为MIT来源的CLOUDS体积采样，低矮、明暗可见，已比较60/75/90%，默认75%；保留暂停和静态回退。

## 云海纵深修订 · 2026-10-30

用户进一步明确：书页是云海的基层，云雾沿纸面纵深铺开，文字若隐若现且可见，鼠标驱动流体移动。将贴底云带改为俯看浅层云海的视角，覆盖书页场景46%–102%区域；高精度体积噪声建立远近疏密，CSS75%与材质alpha0.69共同限制遮挡约52%。上方活文字仍保持清晰。

鼠标以被动pointermove记录ref，160×96双缓冲场执行半拉格朗日平流、局部旋涡与耗散，推开后缓慢回流；没有增加React逐帧state或依赖包。暂停、离屏、后台及减少动态效果均停止运动。此实现是视觉速度场，没有宣称完整压力投影求解器或真实设备FPS保证。首页词条衔接和之后的连续翻页保持；临时离场场景捕获当前WebGL帧，避免云层在点击时消失。
