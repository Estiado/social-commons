# 内容来源与发布约定

更新：2026-10-25。用户要求名句评述有已发表的真实依据，原创观点必须明确标注。

## 新增选题

优先文学、审美、心理学、科技与日常社会观察，新增避开政府政策说明、宣传稿及立场评论。不因用户提到某个热点就勉强建立词条；材料单薄、只有政策说明或不能形成有据阅读的选题暂不收录。本轮不新增金税四期、旭日旗，不批量删除原有内容。具体来源与版本仍逐条维护。

青年研究选读使用具体学术论文，而非政府政策或宣传稿。研究者任职机构不替代文章内容判断。`researchSource`区分论文出版年份与站内录入日期；只读到公开摘要时，不扩写成全文研究结论，不编造访谈人数、样本代表性或因果效果。原站可下载不等于允许本站镜像整篇，未经许可只链接期刊原站PDF。

## 名句与评析

观澜事件遵循同样的证据要求：具体事情先讲清背景，再选择真实著述支持多方视角，编辑比较与追问单独署名。素材、名句和研究依附事件，不以课堂练习替代资料。论文只核对摘要时在维护台账记录范围，不编造全文论证；电子版链接说明题名和实际提供方，不将可下载等同再分发授权。详见GUANLAN_EVENTS.md。

- `quotes.ts` 保留旧 50 个 ID，新增至 98 个 ID；去重推荐 88 篇。无法对应具体公开出处的旧评析已撤下，不再以名家或“研究学者”的名义展示。
- `quoteCommentaries.ts` 只发布逐条核验的资料摘要，必须有具体作者、文章/论文/版本、原文 URL、核验日期与 verified 状态。核验状态保留在内部，读者看到正常的“作品赏析”、评述者与文献标题；不要展示“依据已发布资料整理，非逐字引语”等编辑工作要求，也不能将概述加引号冒充原话。
- 当前 59 篇去重作品具有已发表资料摘要；其余不显示虚构评析或将待办提示混进正文。相同作品的旧 ID 保留，不伪装成多份证据。新增摘要按来源分组在 `quotes/`，来源范围见 `CONTENT_SOURCES.md`。
- 笼统书名、名家身份或网站域名不能充当某段评析的证据。资料观点不表述为唯一结论。
- 不编造引号中的名家原话，不用 AI 解释冒充论文引述。本站推荐理由和使用提示标明“本站整理”或“整理者观点”。
- 名句版本与译文核验和评析核验分开。q8、q10 署名/篇目尚待核对；q29 区分书信篇目和合编书名；q14/q22/q48 修正为悼念 Wolf Graf von Kalckreuth 的《安魂曲》。不能据评析有来源推断所有译文已核验。

维护流程：打开原页/论文 → 查到支持说法的段落 → 写短摘要并在内部区分摘录与概述 → 填 URL、作者、版本、日期 → 核对未扩大原意 → 检查并提交。未找到证据时保留待核验状态。

## 个人素材与站方示例

读者素材存于 `social-commons:concept-materials-v1`，按概念分组，可增改、删除、JSON 备份与恢复，不上传公共表。旧自定义概念素材保留可读，并可复制到新编辑器。

站方示例入口为 `essayExamples.ts`，按来源分组在 `essay/`，共 61 条；`npm run seed:examples` 生成 SQL。`essay_examples` 访客只读；只有服务端维护的 `site_editors` 名单可以写，普通账号不能自行加入名单。研究摘要和虚构教学设例分别标明，不是媒体全文。数据库同 ID 编辑覆盖静态示例，未同步的旧种子不会使新增示例消失。

用户决定先本机内测，邮箱和在线编辑默认关闭。维护者可编辑数据文件、运行 seed、检查并推送发布推荐；未来邮件功能验收后，启用 `VITE_READING_CLOUD_ENABLED=true`，再使用 `/editor/materials` 在线管理。

编辑账号须先验证邮箱，再由可信 Supabase 管理员核对账号后执行以下语句。替换占位邮箱，检查只返回预期账号；不得做成前端接口。

```sql
insert into public.site_editors(user_id)
select id from auth.users
where lower(email) = lower('YOUR_VERIFIED_EDITOR_EMAIL')
  and email_confirmed_at is not null
  and not coalesce(is_anonymous, false)
on conflict do nothing
returning user_id;
```

这只授予公开示例编辑权，不允许读取他人的私有全文和摘录。
