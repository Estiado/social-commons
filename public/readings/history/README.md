# 群鉴电子文献

本目录仅存放已检查的可再分发电子版本，文件不得经格式化工具改写。`manifest.json` 记录来源、大小及 SHA-256，回归检查逐字节验证。根目录 `.gitattributes` 禁止 Git 自动转换这些 TXT 的换行，并豁免原电子版自带的空白排版检查，以保留原始字节；代码文件仍检查空白错误。

- `bradford-plymouth.txt`：布拉福德，Harold Paget 1920 英译/整理本，Project Gutenberg #69871。
- `smith-wealth.txt`：斯密《国富论》，Project Gutenberg #3300。
- `wollstonecraft-rights.txt`：沃斯通克拉夫特《女权辩护》，Project Gutenberg #3420。
- `engels-workers.txt`：恩格斯《英国工人阶级状况》，Florence Kelley Wischnewetzky 译，Project Gutenberg #17306。
- `faxian-kingdoms.txt`：法显《佛国记》，James Legge 英译，Project Gutenberg #2124。
- `cdc-snow-2004.pdf`：CDC《MMWR》2004年第53卷第34期完整电子刊，含斯诺专题。保留整期页码、署名与出版信息。
- `darwin-origin-first.txt`：达尔文《物种起源》1859年初版英文全本，Project Gutenberg #1228。实际下载核对书内初版说明及1859年扉页；不要误标为1872年第六版（#2009）。

六个 TXT 保留原始 Project Gutenberg 全部许可说明；不要移除原有首尾信息。当地公版状态与 Gutenberg 的再分发条件须分别核对。现代论文、国际组织报告及包含第三方图片的整刊，若没有确认整本镜像范围，使用原出版物链接；研究下载留在忽略的 `.artifacts/`，不混入本站托管文件。
